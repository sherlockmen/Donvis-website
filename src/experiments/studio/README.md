# Donvis 首段交互样片 V6

默认首页直接进入，也兼容 `/?study=studio`。从品牌开场滚动到 App 总览、功能展示和品牌末屏，沿用 Vue、Three.js 和 Lenis。

## 当前实现

- 暖金开场放大原版驴头。桌面把两行 slogan 放在驴头左侧，窄屏放在围巾下方。开场文案随滚动逐行退场，末屏文案随滚动逐行出现，反向滚动时按原轨迹返回。
- 驴头取自原版 App 图标，三维围巾贴着下颌叠出两层，从下层领口接出布尾。开场循环播放耳朵摆动、眨眼、坏笑和星星，slogan 用靛蓝和围巾红区分「Agent」与「拉磨」。
- 原图与 WebGL 共用相机投影。布尾在驴头下方兜过，再引向 App 展示。滚动连续推动相机、文字退场和底色过渡，反向滚动沿同一镜头返回。
- 12 个功能各占一屏，各有短标题、说明和完整 App 画面。围巾连接相邻画面，功能文案跟随滚动进出，每屏留出稳定的阅读区间。末屏围巾收回领口，重新露出驴头与「让它们拉磨。把精力，留给创造。」
- 后半段在本机工具、菜单栏、分享屏加入拱起、回卷和斜悬的中途停留；菜单栏和分享屏最终收成下方舒展的松弧，设置保持低处褶皱。末屏由左上角 Donvis 后的原图标起飞放大，不再另设右上角停靠位置。上滑沿原路返回。
- 围巾有纵向褶皱、圆边、细绒和随尾端变形的流苏。领口固定，布尾待机摆动、悬停抬起、拖动时跟随指针，松手回位。也支持方向键、暂停、重置和移动端拖动开关。

## 素材与边界

- 围巾使用实时几何、灯光和 [`scarf-wool-v2.png`](../../assets/scarf-wool-v2.png) 的针织细节呈现。
- App 展示板使用 2000 × 1800 的完整 [Codex 分析示例画面](./app-overview.png)。功能屏使用网页重绘的界面和图表，停留时按比例排版。
- 拖动位移跟随指针，场景避让通过调整深度完成。极端拉扯会拉伸布面，目前没有完整布料自碰撞。减少动态效果或 WebGL 失败时显示静态内容。
